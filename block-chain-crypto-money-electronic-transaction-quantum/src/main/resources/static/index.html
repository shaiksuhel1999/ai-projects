Post-Quantum Security Lab

TekmaChain signs with secp256k1 ECDSA, exactly like Bitcoin. A sufficiently powerful quantum computer running Shor's algorithm could recover an ECDSA private key from its public key — letting it forge signatures and move coins. The defence is post-quantum signatures (NIST's ML-DSA / CRYSTALS-Dilithium, Falcon) whose security doesn't rest on the discrete-log problem.

Below, TekmaChain benchmarks ECDSA against those schemes head-to-head — real key sizes, signature sizes and sign/verify timings measured on this node. The catch: post-quantum signatures are much larger, which is the real cost of putting them on a chain.
